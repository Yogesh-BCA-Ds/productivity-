# DevSpace — Personal Study Dashboard

A calm, coder-themed productivity dashboard built with plain HTML, CSS and JavaScript.

## Features
- Live clock, date and greeting
- Manual study-session tracking with Start / Pause / Finish
- Daily tracked time and activity breakdown
- Session history with date filter
- Notes saved in the current browser
- Export/import JSON backup
- Optional 25-minute focus timer
- Quick links to GitHub, YouTube, WhatsApp, ChatGPT and web search
- Basic offline cache / installable web-app support

## Deploy with GitHub Pages
1. Create a new public repository named `devspace` (or another name).
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment. Your project URL should look like:
   `https://Yogesh-BCA-Ds.github.io/devspace/`
   If you choose a different repository name, replace `devspace` in the URL.

## Add it to your Android home screen
1. Open the deployed URL in Chrome on your phone.
2. Open Chrome's `⋮` menu.
3. Choose **Add to Home screen** or **Install app**, if shown.
4. Launch DevSpace from the new icon.

## Data and privacy
Session history and notes are saved locally in the browser on that device. They are not automatically synced to GitHub or another device. Use **Export history** to save a JSON backup and **Import backup** to restore or merge sessions. Clearing browser/site data may erase local data.

## Limitations
- The dashboard tracks sessions you explicitly start. It cannot automatically see how long you use other Android apps.
- Links open the matching website or app when Android/browser supports it. WhatsApp opens WhatsApp generally; no college group is hard-coded.
- This is a productivity web app, not a replacement Android launcher.
